# CloudBox

CloudBox - учебное веб-приложение облачного файлового хранилища на Flask.

## Возможности

- регистрация и авторизация пользователей;
- роли `user` и `admin`;
- загрузка файлов на сервер;
- просмотр списка файлов и папок;
- скачивание, удаление, переименование и перемещение файлов;
- создание папок;
- поиск файлов по названию;
- хранение метаданных в JSON;
- хранение файлов в файловой системе сервера;
- журнал действий пользователей;
- админ-панель со статистикой и управлением пользователями;
- ограничение размера загружаемого файла до 50 МБ;
- пользовательская квота хранилища;
- избранные файлы;
- корзина с восстановлением и окончательным удалением;
- сортировка файлов по имени, дате, размеру и типу;
- автоматическое определение категории файла по расширению;
- безопасное хранение паролей в виде хеша.

## Запуск

Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запустите приложение:

```bash
flask --app app run --debug --port 5001
```

После запуска откройте в браузере:

```text
http://127.0.0.1:5001
```

## Администратор по умолчанию

При первом запуске приложение автоматически создает администратора:

```text
email: admin@cloudbox.local
password: admin12345
```

Значения можно изменить через переменные окружения:

```text
DEFAULT_ADMIN_USERNAME
DEFAULT_ADMIN_EMAIL
DEFAULT_ADMIN_PASSWORD
SECRET_KEY
USER_QUOTA_BYTES
```

## Хранение данных

Runtime-файлы создаются автоматически:

```text
data/users.json
data/files.json
data/logs.json
storage/users/user_<id>/
```

Эти файлы не добавляются в Git, потому что содержат локальные пользовательские данные. Для отчета и пояснительной записки в каталоге `data/` лежат примеры JSON-структур.
